# deeperthinking.xyz

The posts and pages of [deeperthinking.xyz](https://deeperthinking.xyz), built with [Skimdit](https://github.com/GTKottman/skimdit).

- `content/posts/<slug>/index.md`: published posts, with their images in the same folder
- `content/pages/`: pages such as About and Now

Only published writing lives here. Drafts stay in Skimdit's database and are committed only when published.
